Enterprise AI

AI for Non-Coders

Vibe Engineering & Enablement

Build a working tool for your own role — not a toy demo — in guided hackathon sprints. Day 1: guided first ship, prompting as delegation, and the verification habits that separate robust AI-built apps from fragile ones. Day 2: hackathon sprints on your own scoped project, with automated quality gates and a 3-minute demo of what you built.

  • Build and demo a working tool for your own role, from idea to running — without writing code by hand
  • Apply a verification checklist to any AI-built tool: test with real cases, recognize fragile patterns, state what the tool does not handle
  • Run the iterate loop deliberately — describe, generate, verify, refine — instead of prompt-by-prompt luck
  • Decide and justify when to stop and call an engineer, with explicit escalation criteria
  • Explain your tool to a non-participant in a 3-minute demo story: what it does, where it breaks, what data it touches

Duration: 2 days

Format: Hackathon-style workshop

Prerequisites: No programming experience

Outcome: Build real working tools for your own role using conversational AI — and know when to call an engineer.

Research with AI

Reproducible Research Code

Envs, Data & Verification Debt

Leave with one repo that passes the reproduction test: a clean checkout, one command, and a colleague with no context reproducing your published number. Pin environments, version data, audit the verification debt your AI-assisted code accumulated, and pay it down in a guided sprint.

  • Run and interpret the reproduction test — and gain the fixes the failure demands
  • Pin environments and version data so results survive machine and personnel changes
  • Audit verification debt in your own repo: what was never verified, what it costs, the paydown order
  • Defend against fabricated statistics as an architectural failure — checks at the results boundary, not vigilance at the prompt
  • Rank your code by what happens when it is wrong, and match verification effort to criticality

Duration: 2 days

Format: Hands-on workshop

Prerequisites: Research code you want to make reproducible

Outcome: Make research code and results reproducible under AI assistance: environment pinning, data versioning, and paying down verification debt before it compounds.
